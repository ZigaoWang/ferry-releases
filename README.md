# Ferry — downloads

Ferry compresses images for the web. It picks the format and settings for each image by
measuring the result, rewrites colors into real sRGB rather than relabelling them, and always
strips location data.

**[Download the latest version](https://github.com/ZigaoWang/ferry-releases/releases/latest)**

Requires macOS 15 or later. Ferry is a paid app; the download needs a license key to run.

This repository holds only the downloads and the Sparkle update feed (`appcast.xml`). The
source lives in a private repository.
